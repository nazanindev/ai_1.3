# FastAPI Project Management API

A REST API for managing projects, tasks, and team collaboration, built with FastAPI and SQLAlchemy.

## About

This API provides full project management capabilities with JWT-based authentication protecting every endpoint.

**Data models**

- `User` — accounts with hashed passwords
- `Project` — workspaces with membership control
- `Task` — work items with assignment and status transitions
- `Comment` — discussion threads scoped to individual tasks

**Feature routers**

| Router | Endpoints |
|--------|-----------|
| `users` | register, login, profile |
| `projects` | CRUD, membership management |
| `tasks` | CRUD, assignment, status transitions |
| `comments` | CRUD scoped to a task |

**Stack:** FastAPI · SQLAlchemy · JWT auth · pytest
